# Gloxy AI

مساعد ذكي باللغة العربية يعمل كموقع ويب باستخدام Gemini API.

## التشغيل محلياً
1. ثبّت Node.js 20 أو أحدث.
2. نفّذ `npm install`.
3. أنشئ ملف `.env` اعتماداً على `.env.example` وأضف مفتاح Gemini API.
4. نفّذ `npm start` وافتح `http://localhost:3000`.

## النشر على Vercel
1. استورد المستودع `MWN-git/Gloxy-AI` من GitHub إلى Vercel.
2. اترك Framework Preset على Other، ومجلد الإخراج مضبوط في `vercel.json` إلى `public`.
3. أضف متغير البيئة `GEMINI_API_KEY` في إعدادات المشروع على Vercel.
4. أضف `GEMINI_MODEL` اختيارياً؛ القيمة الافتراضية هي `gemini-3.8-flash`.
5. انشر المشروع.

لا تضع مفتاح API في ملفات الواجهة أو في GitHub، ولا ترسله في المحادثات.

## ملاحظات
- واجهة الموقع ثابتة في مجلد `public`، وواجهة Gemini تعمل كـ Vercel Node.js Function في `api/chat.js`.
- الحد الأقصى للملف المرفق 3 MB لتقليل احتمال تجاوز حد جسم الطلب في Vercel Functions.
- تحديد الطلبات الحالي داخل الذاكرة إجراء أولي فقط، وليس نظام حماية موزعاً أو ضماناً لمنع إساءة الاستخدام.
- حصص Gemini المجانية محدودة وقد تتغير. تجنب إرسال معلومات حساسة.
